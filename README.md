## 🚀 How to Run the Website

### Option 1: Instant Launch (No installation needed)
Double-click `open_website.bat` or open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Firefox, Brave, Safari).

### Option 2: Local HTTP Server (Python)
```bash
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.

### Option 3: Node / npm
```bash
npm start
```
